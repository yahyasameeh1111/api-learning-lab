⚡ Supabase Database Setup & SQL Schema

              
Copy and paste this script into your Supabase Dashboard → SQL Editor to create the products table and Row Level Security (RLS) policy.

            

            
          


          
-- 1. Create products table in PostgreSQL database
create table if not exists public.products (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  title text not null,
  price numeric not null,
  category text not null,
  description text,
  rating numeric default 4.5,
  thumbnail text default 'https://images.unsplash.com/photo-1523275335684-37898b6baf30?w=400&q=80'
);

-- 2. Enable Row Level Security (RLS)
alter table public.products enable row level security;

-- 3. Create Public Access Policy for full CRUD API access
create policy "Allow Public CRUD Access" on public.products
  for all using (true) with check (true);

-- 4. Seed initial products
insert into public.products (title, price, category, description, rating, thumbnail) values

Successful GET / PUT / DELETE

            
The standard response for successful HTTP requests. The actual response payload depends on the method used.

            

              GET /products/1 → 200 OK
            

            
          


          
          

            

              201 Created
              Success
            

            
Resource Created Successfully

            
The request succeeded, and a new resource was created on the server as a result (typically returned by POST requests).

            

              POST /products/add → 201 Created
            

            
          


          
          

            

              400 Bad Request
              Client Error
            

            
Malformed Syntax or Validation Error

            
The server cannot process the request due to something perceived to be a client error (e.g. invalid JSON, missing parameters).

            

              POST /products/add (invalid body) → 400
            

            
          


          
          

            

              401 Unauthorized
              Client Error
            

            
Authentication Required

            
The request lacks valid authentication credentials for the requested resource (missing JWT token, API key, etc.).

            

              GET /auth/me (no header) → 401
            

            
          


          
          

            

              403 Forbidden
              Client Error
            

            
Permission Denied

            
The client identity is authenticated, but does not have permission rights to access the specified resource.

            

              DELETE /resource/1 → 403
            

            
          


          
          

            

              404 Not Found
              Client Error
            

            
Resource Does Not Exist

            
The server cannot find the requested URL path or product ID. Often happens when requesting non-existent IDs.

            

              GET /products/999999 → 404 Not Found
            

            
          


          
          

            

              500 Server Error
              Server Error
            

            
Internal Server Crash

            
The server encountered an unexpected condition that prevented it from fulfilling the request. Usually an uncaught backend exception.

            

              POST /server-crash → 500 Server Error
