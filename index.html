What is an API?

An API (Application Programming Interface) is a bridge that lets two systems communicate. A client sends an HTTP Request to an endpoint, and the server returns a JSON Response.

What is CRUD?

CRUD represents the 4 core database operations mapped to HTTP methods:

  • GET Read (Retrieve data)
  • POST Create (New resource)
  • PUT Update (Modify resource)
  • DELETE Delete (Remove resource)

HTTP Request Lifecycle

When your application calls fetch(), a request travels over HTTPS with headers and optional body data. The server processes it, checks auth & logic, then returns a status code (e.g. 200 OK) with response data.

HTTP Status Code Reference Guide

HTTP status codes inform the client whether a specific HTTP request has been successfully completed. Learn the standard response classes with interactive live simulations.

200 OK Success

Successful GET / PUT / DELETE

The standard response for successful HTTP requests. The actual response payload depends on the method used.

GET /products/1 → 200 OK
201 Created Success

Resource Created Successfully

The request succeeded, and a new resource was created on the server as a result (typically returned by POST requests).

POST /products/add → 201 Created
400 Bad Request Client Error

Malformed Syntax or Validation Error

The server cannot process the request due to something perceived to be a client error (e.g. invalid JSON, missing parameters).

POST /products/add (invalid body) → 400
401 Unauthorized Client Error

Authentication Required

The request lacks valid authentication credentials for the requested resource (missing JWT token, API key, etc.).

GET /auth/me (no header) → 401
403 Forbidden Client Error

Permission Denied

The client identity is authenticated, but does not have permission rights to access the specified resource.

DELETE /admin/users/1 → 403
404 Not Found Client Error

Resource Does Not Exist

The server cannot find the requested URL path or product ID. Often happens when requesting non-existent IDs.

GET /products/999999 → 404 Not Found
500 Server Error Server Error

Internal Server Crash

The server encountered an unexpected condition that prevented it from fulfilling the request. Usually an uncaught backend exception.

POST /server-crash → 500 Server Error
